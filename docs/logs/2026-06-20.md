# Work Log - 2026-06-20

## Summary

Diagnosed and fixed garbled Chinese text in the daily podcast video slides. Root cause was a missing CJK font in the Render (Linux) cloud environment. Bundled Noto Sans CJK TC into the repo, wired it into the font search order and Render config, then backfilled all 15 previously-rendered videos so their Chinese no longer shows as tofu.

## Root Cause

- Video slides are rendered with Pillow in `workers/daily_pipeline/generate_podcast_video.py`; text needs a font with CJK glyphs.
- `_load_font()` search order ended at `C:/Windows/Fonts/msjh.ttc` (Windows-only), a few probed Linux Noto/WenQuanYi paths, then `DejaVuSans.ttf` / `load_default()`.
- Local dev is Windows, so `msjh.ttc` was found and output looked fine.
- The daily video runs on Render Cron (Linux, Singapore). Windows fonts are absent, and the probed Noto CJK paths were never installed — `workers/requirements.txt` only installs `pillow` and `imageio-ffmpeg`, and Render's native Python runtime cannot `apt-get` fonts.
- Pillow therefore fell back to `DejaVuSans` (no CJK glyphs) → Chinese rendered as tofu boxes. English was fine because DejaVuSans covers Latin.
- `PYTHONIOENCODING=utf-8` is unrelated; it only affects console output encoding, not glyph rendering.

## Completed Work
